Factory Inventory Management — System Architecture

Two‑tier SPA: Vue 3 frontend talking to a FastAPI backend over REST, with JSON fixture files as the in‑memory data store.

Tech Stack

Frontend

Vue 3 SPA

  • Vue 3.5 — Composition API
  • Vue Router 4 — client routing
  • Axios — HTTP client
  • Vite 5 — dev server / bundler
  • Port 3000
Backend

Python FastAPI

  • FastAPI — REST endpoints
  • Pydantic 2 — validation / serialization
  • Uvicorn — ASGI server
  • CORS — allow‑all (dev)
  • Port 8001
Data & Tests

JSON Fixtures

  • 7 JSON files in server/data/
  • Loaded into memory at startup
  • Read‑only, non‑persistent
  • pytest + httpx TestClient

System Architecture

Request Data Flow

1 · Vue View
onMounted / watch reads useFilters() reactive state and calls api.getInventory(filters).
→
2 · api.js
Axios builds query string and issues GET :8001/api/inventory?warehouse=…&category=….
→
3 · FastAPI
Route handler reads in‑memory list from mock_data, runs apply_filters() / filter_by_month().
→
4 · Response
Pydantic serializes → JSON → CORS → view assigns to ref → reactive re‑render.

Shared filter state: useFilters composable is the single source of truth for warehouse / category / status / month. FilterBar.vue writes to it; every view watches it and refetches.
